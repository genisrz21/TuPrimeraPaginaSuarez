# TuPrimeraPaginaSuarez

# Es una pagina web estilo blog que permite gestionar información mediante formularios y consultas a la base de datos

# El sistema incluye: agregar autor, categoria y articulo, y un buscador de los articulos creados con los formularios

# Para ejecutar el proyecto: 
# Clonar el repositorio:

# git clone https://github.com/genisrz21/TuPrimeraPaginaSuarez

# Acceder a la carpeta del proyecto:

# cd TuPrimeraPaginaSuarez

# Aplicar migraciones:

# python manage.py makemigrations
# python manage.py migrate

# Ejecutar el servidor:

# python manage.py runserver

# Abrir en el navegador:

# http://127.0.0.1:8000/
